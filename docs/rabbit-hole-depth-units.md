# Rabbit-hole depth units

For consistency, all rabbit-hole depth measurements should use the following
strictly scientific scale:

- 0 tabs: touching grass
- 1–4 tabs: casual curiosity
- 5–12 tabs: a respectable tunnel
- 13–29 tabs: the Warren Buffett stage (unrelated to finance)
- 30+ tabs: you live here now

This document changes no runtime behavior, stores no data, and should not be
used for billing, incident response, or actual science.
